# ⛰️ Zirve Top Yarışı

Dağın zirvesinden aşağı yuvarlanan topların yarıştığı 3D yarış oyunu (three.js). Tarayıcıda çalışır.

**▶ Oyna:** https://ysf-creator1.github.io/zirve-top-yarisi/

- İnternetten açılınca kayıtlar o cihazın tarayıcısında saklanır.
- **Mac'te kalıcı kayıtla oynamak:** klasördeki **Zirve Top Yarışı** uygulamasına çift tıkla (ilk seferde sağ tık → Aç). Kayıtlar `kayit/kayit.json` dosyasına yazılır.
- **Windows / diğer:** `python3 sunucu.py` çalıştır ya da `index.html` dosyasını aç.

Lisans: three.js (MIT)
